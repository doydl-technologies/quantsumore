# Security policy

## Supported versions

No version of `quantsumore` is supported. The project does not receive security
updates, dependency updates, compatibility fixes, or vulnerability triage.

## Reporting vulnerabilities

There is no active private security-reporting or response process for this
retired project. Reports may not be reviewed or acknowledged.

Do not use `quantsumore` in production or security-sensitive environments. If
continued use is unavoidable, independently audit and maintain a fork, pin and
review its dependencies, and assess the risks of every third-party data source.

See [ARCHIVED.md](ARCHIVED.md) for the complete retirement notice.
